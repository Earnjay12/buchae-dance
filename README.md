# 아름다운 나라 부채춤 · 19명 대형

학예회 부채춤 영상을 1초 단위로 분석해 **19명(여 10 · 남 9)** 용으로 다시 짠 연습 페이지입니다.

https://earnjay12.github.io/buchae-dance/

- 영상과 대형도를 나란히 놓고 한 프레임씩 넘겨 보기(영상 파일 열기 또는 유튜브)
- 2~4초(박) 단위로 19명 전원의 자리 · 발 · 팔 · 부채(방향·높이) · 시선 · 이동(걸음 수, 기다렸다 출발, 누구 뒤로 지나가는지)
- 위에서 본 대형 / 객석에서 본 그림, 핵심 대형 20장면, 학생별 동선표 인쇄, 부채 동작 사전, 안전 동선 점검

## 고치는 법

- 안무 데이터: `js/choreo.js` (대형 = `F`, 구간·박 = `S`, 동작 사전 = `P`)
- 고친 뒤 `node tools/check.js` → 간격·충돌·속도 점검 후 `js/plan-data.js`(우회 경로·출발 박)를 다시 만듭니다.
- 영상 파일(mp4)은 저장소에 올리지 않습니다. 내 컴퓨터에서 `python tools/serve.py 5186`으로 열면 같은 폴더의 영상을 자동으로 불러옵니다.
